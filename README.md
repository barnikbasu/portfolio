## Key Features

- **Atmospheric Dark UI** — deep black background with warm orange-red glow orbs for a cinematic feel
- **Typewriter Hero** — cycles through four roles at 80ms per character with a blinking orange-red cursor
- **BB Monogram** — large gradient monogram with floating tech badges and offset float animations
- **Industry Simulation Cards** — EA, AWS, and Deloitte cards with shimmer border animation and distinction badges
- **SafeRoute Showcase** — featured project card with live demo, GitHub link, and Top 10 hackathon badge
- **Beyond the Code** — dedicated music section with dot-grid texture and italic quote
- **Scroll Reveal** — Intersection Observer fade-in and slide-up on every section
- **Fully Responsive** — mobile hamburger overlay nav, adaptive grids, scaled monogram

## Getting Started

```bash
# Clone the repo
git clone https://github.com/barnikbasu/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
# Open http://localhost:3000

# Build for production
npm run build
```
