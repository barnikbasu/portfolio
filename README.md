# Barnik Basu | Developer Portfolio

A high-end, dark-themed single-page developer portfolio built with **React**, **Tailwind CSS**, and **Framer Motion**. Designed for a B.Tech Computer Science student at IIIT Kalyani, highlighting a unique blend of technical expertise (Data Analytics, ML, Open Source) and artistic discipline (Indian Classical Musician - Sarod Player).

## 🚀 Live Demo
**[barnikbasu.vercel.app](https://barnikbasu.vercel.app/)**

## 🛠️ Tech Stack
- **Frontend:** React 19
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion (`motion/react`)
- **Icons:** Lucide React
- **Typography:** Syne & JetBrains Mono (via Google Fonts)
- **Deployment:** Vercel

## ✨ Key Features
- **Atmospheric Dark UI:** A sophisticated "dark room with a distant fire" aesthetic using deep black backgrounds and warm orange-red accents.
- **Dynamic Hero Section:** Features a custom typewriter effect cycling through professional roles and floating tech badges orbiting a 3D-style monogram.
- **Interactive Project Cards:** Detailed showcase of projects like **SafeRoute** (AI-powered navigation) and **Circuit Breakers** (Robotics).
- **Industry Simulations:** Dedicated section for professional simulations from **Electronic Arts**, **AWS**, and **Deloitte Australia** with unique shimmer-border effects.
- **Beyond the Code:** A special section celebrating musical achievements as a classical Sarod player, emphasizing the connection between music and pattern recognition in code.
- **Fully Responsive:** Seamless experience across mobile, tablet, and desktop devices with a clean overlay navigation menu for mobile.

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/barnikbasu/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
